Practice · Lesson 1.2 · Primary and secondary sources: origin, purpose, and context

Four activities · the order of the exercises changes every time · two tries in each one

On this page

  1. Primary or secondary?
  2. Origin, purpose, or context?
  3. Supports or does not support?
  4. Which document answers it?
1

Primary or secondary?

›

Ask: does the source belong to the world it describes, or does it look at it from outside and later? Watch the last two: the same movie changes category with the question.

↑ Back to contents
2

Origin, purpose, or context?

›

Each case gives six details about one document. Decide which of the three questions each detail answers. If something is not right, the details marked in yellow get a hint.

↑ Back to contents
3

Supports or does not support?

›

Use the two documents of the lesson (A: Addams; B: Holbrook). A document supports a claim only if you can point to the line it rests on.

↑ Back to contents
4

Which document answers it?

›

For each question, choose the document that helps, both, or neither. Sometimes the honest answer is that you need another source.
