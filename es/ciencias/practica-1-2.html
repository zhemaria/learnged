El invernadero: aísle la variable

›

Los grupos A y B empiezan iguales: luz, riego, temperatura y suelo habituales. Cambie los factores de cualquiera de los dos grupos y pulse Hacer el ensayo. A las seis semanas verá la altura media de cada grupo y si el resultado permite concluir algo. El modelo da siempre el mismo resultado para el mismo montaje, como debe ser en un buen experimento.

Cuaderno de laboratorio: cada ensayo, qué cambió entre A y B, la altura media de cada grupo y si se puede concluir algo

Reto: encuentre la mejor luz para las plantas. Después, el mejor suelo. ¿Cuántos ensayos necesitó? ¿Cambió alguna vez dos cosas a la vez?
