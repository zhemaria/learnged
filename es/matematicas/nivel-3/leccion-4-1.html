🎯Lo que va a aprender

Al terminar esta lección, usted podrá:

1Variables, términos y coeficientes

El lenguaje algebraico no es del todo nuevo: en el Nivel 1 ya se trabajó con incógnitas simples para resolver problemas de un paso. Lo que cambia aquí es la profundidad. Tras completar el sentido numérico en los Temas 1 al 3 de este nivel (exponentes, notación científica y números reales), el Nivel 3 retoma y formaliza ese lenguaje: se trabajará la traducción completa entre palabras y símbolos, y se aprenderá a simplificar expresiones distribuyendo y combinando términos semejantes. Esa base permitirá, en las próximas lecciones, resolver ecuaciones.

Una variable es una letra que representa un número desconocido o que puede cambiar. Una expresión algebraica combina variables, números y operaciones. Sus partes tienen nombres precisos:

Partes de la expresión 3x más 5: término, coeficiente, variable y constante
ParteEn 3x + 5Significado
Término3x y 5Cada parte separada por + o −.
Coeficiente3El número que multiplica a la variable.
VariablexLa letra que representa el valor desconocido.
Constante5El término que no tiene variable.

Coeficiente invisible

Cuando una variable aparece sola, como x, su coeficiente es 1 (x = 1x). De igual modo, −x significa −1x. Recordarlo evita errores al combinar términos.

2Traducir entre palabras y álgebra

Gran parte del álgebra consiste en traducir un enunciado verbal al lenguaje de los símbolos. Ciertas palabras señalan siempre la misma operación.

El orden importa en la resta

«Un número disminuido en 4» es x − 4, pero «4 disminuido en un número» es 4 − x. Y «4 menos que un número» es x − 4: al número se le quitan 4. La resta no es conmutativa, así que conviene leer con cuidado quién va primero.

3Combinar términos semejantes

Dos términos son semejantes si tienen la misma variable elevada al mismo exponente. Solo los términos semejantes se pueden combinar, sumando o restando sus coeficientes.

Ejemplo 1: simplifique 3x + 5x

1¿Semejantes? Los dos términos tienen la variable x: son semejantes.

2Sumar los coeficientes. 3 + 5 = 8.

✓Respuesta. 3x + 5x = 8x

Ejemplo 2: simplifique 7x − 2x + 4

1Los términos con x. 7x − 2x = 5x.

2La constante. El 4 no tiene x: se deja aparte.

✓Respuesta. 7x − 2x + 4 = 5x + 4

No se combinan términos distintos

4x + 2y no se puede simplificar, porque x y y son variables diferentes. Tampoco 3x + 5 se reduce a 8x, porque el 5 no tiene la variable x. Y 3x2 + 2x no es 5x2: los exponentes son distintos.

4La propiedad distributiva

La propiedad distributiva permite multiplicar un número por una suma, repartiéndolo a cada término del paréntesis.

a(b + c) = a · b + a · c

Ejemplo 3: simplifique 3(x + 4)

1Repartir el 3. 3 · x + 3 · 4.

✓Respuesta. 3(x + 4) = 3x + 12

Ejemplo 4: simplifique 2(x + 3) + 4x

1Distribuir. 2x + 6 + 4x.

2Combinar los semejantes. 2x + 4x = 6x.

✓Respuesta. 2(x + 3) + 4x = 6x + 6

El signo también se reparte

−2(x − 5) = −2x + 10, porque (−2)(−5) = +10. El error más frecuente es multiplicar solo el primer término: 3(x + 4) no es 3x + 4.

5Evaluar expresiones

Evaluar una expresión significa sustituir la variable por un valor dado y calcular el resultado, respetando el orden de las operaciones (PEMDAS).

Ejemplo 5: evalúe 2x + 5 cuando x = 3

1Sustituir. 2(3) + 5.

2Multiplicar primero. 6 + 5.

✓Respuesta. 2x + 5 = 11 cuando x = 3.

Ejemplo 6: evalúe x2 + 1 cuando x = 4

1Sustituir. (4)2 + 1.

2La potencia primero. 16 + 1.

✓Respuesta. x2 + 1 = 17 cuando x = 4.

Use paréntesis al sustituir

Escribir 2(3) en lugar de 23 evita confundir la multiplicación con un número de dos cifras. Con negativos es imprescindible: si x = −3, entonces x2 = (−3)2 = 9, pero −x2 = −(−3)2 = −9.

6Tarea

Esta es práctica independiente. Calcule alrededor de una hora, con su cuaderno abierto.

  • La página de práctica. Abra la página de práctica de esta lección y haga cada actividad. Los ejercicios cambian cada vez. Haga por lo menos 10 en cada actividad y siga hasta acertar 8 de 10 al primer intento. El marcador de cada actividad lleva la cuenta por usted.

➡️Lo que viene

En esta lección se retomó y formalizó el lenguaje algebraico iniciado en el Nivel 1: una variable representa una cantidad desconocida, y con ella se escriben expresiones que se traducen del lenguaje verbal, se simplifican combinando términos semejantes y aplicando la propiedad distributiva, y se evalúan sustituyendo valores.

En la Lección 4.2 · Resolver ecuaciones lineales se dará el siguiente paso: cuando una expresión se iguala a otra, aparece una ecuación, y el objetivo será encontrar el valor de la variable que la hace verdadera. Simplificar y combinar términos, como se aprendió aquí, será el primer paso de toda resolución.

📘Términos clave

variable
Una letra que representa un número desconocido o que puede cambiar, como x.
coeficiente
El número que multiplica a la variable. En 3x, es 3.
términos semejantes
Términos con la misma variable elevada al mismo exponente, como 3x y 7x.
evaluar
Sustituir la variable por un valor y calcular el resultado.
