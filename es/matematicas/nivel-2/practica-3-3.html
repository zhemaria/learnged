PEMDAS con fracciones

›

Las fracciones no cambian el orden. Para sumar o restar se busca un denominador común; para multiplicar, numerador por numerador y denominador por denominador; para dividir, se multiplica por el recíproco. Y el paréntesis de (a/b)2 eleva la fracción completa.

Sustituir y evaluar

›

Regla 1: sustituya siempre entre paréntesis; el paréntesis protege el signo. Regla 2: la letra pegada a un número indica multiplicación: 3x = 3 × x.
