Lección 4.3 · La fórmula cuadrática, el discriminante y aplicaciones

Resuelva cualquier ecuación cuadrática con la fórmula, prediga el número de soluciones con el discriminante y modele la trayectoria de un proyectil.

⏱️ Unas 4 horas con la práctica y la tarea · tome descansos 🧮 Se permiten calculadora y hoja de fórmulas

🎯Lo que va a aprender

Al terminar esta lección, usted podrá:

  • Identificar a, b y c con sus signos y aplicar la fórmula cuadrática.
  • Calcular el discriminante y usarlo para predecir el número de soluciones reales.
  • Resolver problemas de la trayectoria de un proyectil e interpretar las soluciones.
  • Elegir el método más conveniente: factorización, completar el cuadrado o la fórmula.

1La fórmula cuadrática

Conexión con la lección anterior. En la Lección 4.2 se vio que completar el cuadrado en la ecuación general produce la fórmula cuadrática. Ahora se usará esa fórmula directamente: con ella se resuelve cualquier ecuación cuadrática, se factorice o no. En esta lección se permite el uso de la calculadora y de la hoja de fórmulas del GED.

Para cualquier ecuación en forma estándar ax² + bx + c = 0, las soluciones son:

x = (−b ± √(b² − 4ac)) / 2a

El primer paso siempre es identificar a, b y c con sus signos. Por ejemplo, en 2x² − 4x − 3 = 0: a = 2, b = −4, c = −3.

Cuide los signos de b y c

El valor de b incluye su signo. En −b, un b negativo se vuelve positivo. Sustituir con paréntesis, por ejemplo (−4)², evita los errores de signo más frecuentes: (−4)² = 16, nunca −16.

2El discriminante: ¿cuántas soluciones?

La parte de la fórmula que está dentro de la raíz, b² − 4ac, se llama discriminante. Su signo revela cuántas soluciones reales tiene la ecuación antes de resolverla:

Relación entre el signo del discriminante y el número de soluciones reales
Discriminante b² − 4acSoluciones realesLa parábola y el eje x
mayor que 02 soluciones distintaslo corta en 2 puntos
igual a 01 solución (doble)lo toca en 1 punto
menor que 0ninguna solución realno lo toca

Ejemplo 1 · ¿Cuántas soluciones tiene x² + 3x + 5 = 0?

1a = 1, b = 3, c = 5.

2Discriminante: (3)² − 4(1)(5) = 9 − 20 = −11.

3Como −11 < 0, no hay soluciones reales.

✓Respuesta. Ninguna solución real.

Calcule primero el discriminante

Antes de resolver, pregúntese: «¿cuántas soluciones espero?». Así sabrá si la ecuación tiene dos, una o ninguna, y detectará errores si su resultado no coincide con esa predicción.

3Resolver con la fórmula

Ejemplo 2 · Soluciones enteras. Resolver x² + 5x + 6 = 0 con la fórmula.

1a = 1, b = 5, c = 6.

2Discriminante: 5² − 4(1)(6) = 25 − 24 = 1.

3x = (−5 ± √1) / 2 = (−5 ± 1) / 2.

4x = −2 o x = −3.

✓Soluciones. x = −2 y x = −3.

Ejemplo 3 · Con calculadora (raíz no exacta). Resolver 2x² − 4x − 3 = 0.

1a = 2, b = −4, c = −3.

2Discriminante: (−4)² − 4(2)(−3) = 16 + 24 = 40.

3x = (4 ± √40) / 4. Con calculadora, √40 ≈ 6.32.

4x ≈ (4 + 6.32) / 4 ≈ 2.58 o x ≈ (4 − 6.32) / 4 ≈ −0.58.

✓Soluciones (aproximadas). x ≈ 2.58 y x ≈ −0.58.

✏️

Práctica 4 — x² + 7x + 10 = 0

Seleccione las soluciones.

✏️

Práctica 5 — x² − 3x − 10 = 0

Seleccione las soluciones.

4Aplicación: la trayectoria de un proyectil

Las funciones cuadráticas modelan la altura de un objeto lanzado al aire. Si h(t) es la altura (en pies) a los t segundos, resolver h(t) = 0 indica cuándo toca el suelo, y resolver h(t) = un valor indica cuándo alcanza esa altura.

h(t) = −16t² + v₀t + h₀

v₀ es la velocidad inicial (en pies por segundo) y h₀ es la altura desde la que se lanza (en pies). El −16 viene de la gravedad y siempre es el mismo cuando se mide en pies.

Ejemplo 4 · Una pelota se lanza y su altura es h(t) = −16t² + 96t + 5. ¿Cuándo toca el suelo? (usar calculadora)

1Tocar el suelo significa h(t) = 0: −16t² + 96t + 5 = 0.

2a = −16, b = 96, c = 5.

3Discriminante: 96² − 4(−16)(5) = 9,216 + 320 = 9,536. √9,536 ≈ 97.65.

4t = (−96 ± 97.65) / (−32). t ≈ −0.05 o t ≈ 6.05.

5Se descarta la raíz negativa; queda t ≈ 6.05.

✓Respuesta. La pelota toca el suelo a los 6.05 segundos, aproximadamente.

Interprete el contexto

En problemas de tiempo y altura, las soluciones negativas no tienen sentido (el tiempo no es negativo). La solución válida es la que corresponde a la situación real descrita.

5Tres métodos: ¿cuál conviene?

Ya se conocen tres formas de resolver una ecuación cuadrática. Saber elegir ahorra tiempo:

Comparación de los tres métodos para resolver ecuaciones cuadráticas y cuándo conviene cada uno
Método¿Cuándo conviene?
FactorizaciónCuando el trinomio se factoriza fácilmente con enteros.
Completar el cuadradoCuando a = 1 y b es par; útil para entender la estructura.
Fórmula cuadráticaSiempre funciona; ideal cuando no se factoriza o las raíces no son enteras.

Tres preguntas, en orden

¿El trinomio se factoriza fácilmente con enteros? Entonces factorice. Si no, ¿a = 1 y b es par? Entonces complete el cuadrado. En cualquier otro caso, use la fórmula cuadrática, que siempre funciona.

📘Términos clave

fórmula cuadrática
x = (−b ± √(b² − 4ac)) / 2a
discriminante
b² − 4ac: positivo, dos soluciones; cero, una; negativo, ninguna real.
solución doble
Cuando el discriminante es 0, las dos soluciones son el mismo número.
parábola
La gráfica en forma de U de una función cuadrática. Sus cortes con el eje x son las soluciones reales.
vértice
El punto más alto (o más bajo) de una parábola; en un lanzamiento, la altura máxima.
