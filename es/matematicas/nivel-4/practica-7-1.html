Lección 7.1 · Sistemas de desigualdades lineales: graficar la región solución

Cuatro actividades de práctica en una sola página. Los ejercicios cambian cada vez. Si se equivoca, recibe una pista y otra oportunidad.

En esta página

  1. Graficar una desigualdad lineal
  2. El método del punto de prueba
  3. El sistema y la región factible

1

Graficar una desigualdad lineal

›

Elija el símbolo y mueva la pendiente (m) y el intercepto (b) de y … mx + b. Observe cómo la línea se vuelve sólida o punteada y cómo se mueve el sombreado.

Practique: ¿qué desigualdad está graficada?

2

El método del punto de prueba

›

Elija una desigualdad y un punto de prueba. El punto se sustituye: si cumple la desigualdad, se sombrea su lado; si no, el lado contrario.

Practique: ¿qué lado se sombrea?

↑ Volver al contenido
3

El sistema y la región factible

›

Un sistema se grafica una desigualdad a la vez. La región factible (en verde) es la zona donde se traslapan todos los sombreados. Añada las desigualdades y observe cómo se recorta la región.

Cada desigualdad recorta, nunca agranda. Con una condición más, la región solo puede quedarse igual o hacerse más pequeña, y a veces desaparece: entonces el sistema no tiene solución.

Practique: ¿qué sistema tiene esta región?

↑ Volver al contenido
4

Verificar si un punto pertenece a la región

›

Para saber si un punto pertenece a la región no hace falta el dibujo: se sustituye en todas las desigualdades. Si las cumple todas, está dentro; si falla en una sola, está fuera.

Pruebe puntos justo sobre una frontera: ahí se nota la diferencia entre < y ≤.

Practique: ¿está en la región?
