Lección 4.2 · Completar el cuadrado

Complete el cuadrado para resolver cualquier ecuación cuadrática: sume (b/2)², escriba un binomio al cuadrado y saque la raíz con ±.

⏱️ Unas 4 horas con la práctica y la tarea · tome descansos ✏️ Sin calculadora

🎯Lo que va a aprender

Al terminar esta lección, usted podrá:

  • Explicar la idea de completar el cuadrado con el modelo del área.
  • Resolver ecuaciones cuadráticas completando el cuadrado con cinco pasos.
  • Dividir primero entre a cuando el coeficiente de x² no es 1, y calcular (b/2)², incluso como fracción.
  • Seguir cómo completar el cuadrado conduce a la fórmula cuadrática.

1La idea visual: completar un cuadrado

Conexión con la lección anterior. En la Lección 4.1 se resolvieron ecuaciones cuadráticas por factorización. Pero hay ecuaciones que no se factorizan con números enteros. Completar el cuadrado es un método que funciona siempre, factorice o no la ecuación, y además es la base de la fórmula cuadrática.

La expresión x² + 6x se puede representar como un cuadrado de lado x más un rectángulo de área 6x. Si ese rectángulo se parte por la mitad y se coloca una mitad a cada lado, falta un pedacito cuadrado para «completar» un cuadrado grande. Ese pedacito es (6/2)² = 9.

x² + 6x + 9 = (x + 3)²

Al sumar ese término que falta, x² + 6x + 9 se convierte en el cuadrado perfecto (x + 3)². Esa es la idea central: agregar el término justo para formar un binomio al cuadrado.

2Los cinco pasos (cuando a = 1)

Los cinco pasos para resolver una ecuación cuadrática completando el cuadrado
PasoAcción
1Dejar los términos con x a un lado: x² + bx = −c.
2Sumar (b/2)² a ambos lados.
3Escribir el lado izquierdo como (x + b/2)².
4Sacar la raíz cuadrada de ambos lados, con ±.
5Resolver para x.

↔ Deslice la tabla horizontalmente para ver todas las columnas.

Ejemplo 1 · Resolver x² + 6x − 7 = 0.

1x² + 6x = 7.

2(6/2)² = 9. Se suma 9 a ambos lados: x² + 6x + 9 = 16.

3(x + 3)² = 16.

4x + 3 = ±4.

5x = −3 + 4 = 1 o x = −3 − 4 = −7.

✓Soluciones. x = 1 y x = −7.

Ejemplo 2 · Resolver x² − 4x − 5 = 0.

1x² − 4x = 5.

2(−4/2)² = 4. Se suma 4: x² − 4x + 4 = 9.

3(x − 2)² = 9.

4x − 2 = ±3.

5x = 5 o x = −1.

✓Soluciones. x = 5 y x = −1.

No olvide el signo ±

Al sacar la raíz cuadrada de ambos lados aparecen dos resultados, el positivo y el negativo. Omitir el signo ± hace perder una de las dos soluciones.

3Cuando a ≠ 1: dividir primero

El método de los cinco pasos asume que el coeficiente de x² es 1. Si no lo es, el primer movimiento es dividir toda la ecuación entre a.

Ejemplo 3 · Resolver 2x² + 8x − 10 = 0.

1Se divide todo entre 2: x² + 4x − 5 = 0.

2x² + 4x = 5.

3(4/2)² = 4. Se suma 4: (x + 2)² = 9.

4x + 2 = ±3.

5x = 1 o x = −5.

✓Soluciones. x = 1 y x = −5.

Divida la ecuación completa

Al dividir entre a, se dividen todos los términos, incluido el término independiente. Así el coeficiente de x² queda en 1 y los cinco pasos funcionan tal cual.

Siempre positivo

Aunque b sea negativo, (b/2)² es positivo: (−5)² = 25. Cuando b es impar, el resultado es una fracción: (5/2)² = 25/4.

5El origen de la fórmula cuadrática

Si se completa el cuadrado en la ecuación general ax² + bx + c = 0 (sin números, solo letras), el resultado es exactamente la fórmula cuadrática:

x = (−b ± √(b² − 4ac)) / 2a

Por eso este método es tan importante: no es un truco aislado, sino la demostración de dónde proviene la fórmula que se usará en la Lección 4.3 para resolver cualquier ecuación cuadrática.

La derivación, paso a paso (los mismos pasos de la sección 3, con letras)

1Se divide todo entre a: x² + (b/a)x + c/a = 0.

2Se pasa la constante al otro lado: x² + (b/a)x = −c/a.

3Se suma la mitad del coeficiente de x, al cuadrado, en ambos lados: (b/2a)² = b²/4a². x² + (b/a)x + b²/4a² = b²/4a² − c/a.

4El lado izquierdo es un cuadrado perfecto, y el derecho se escribe con denominador común: (x + b/2a)² = (b² − 4ac)/4a².

5Se saca raíz cuadrada sin olvidar el ±: x + b/2a = ±√(b² − 4ac) / 2a.

6Se despeja x restando b/2a: x = (−b ± √(b² − 4ac)) / 2a.

✓Resultado: la fórmula cuadrática, la misma que aparece en la hoja de fórmulas del GED.

6Tarea

Esta es práctica independiente. Calcule alrededor de una hora, con su cuaderno abierto.

  • La página de práctica. Abra la página de práctica de esta lección y haga cada actividad. Los ejercicios cambian cada vez. Haga por lo menos 10 en cada actividad y siga hasta acertar 8 de 10 al primer intento. El marcador de cada actividad lleva la cuenta por usted.
  • Papel y lápiz. Para hacer por su cuenta, con el cuaderno abierto: (1) De la figura al algoritmo: resuelva x² + 6x = 7 y x² + 4x = 12 dibujando el modelo del área. Luego aplique los cinco pasos a x² + 8x + 7 = 0, x² − 10x + 16 = 0, x² + 2x − 8 = 0, x² − 6x − 3 = 0, 2x² + 8x − 10 = 0 y 3x² − 12x + 6 = 0. En cada una, anote cuál es el término (b/2)² que completa el cuadrado. (2) La derivación: después de estudiar los seis pasos de la sección 5, cierre la lección y complete usted el cuadrado en ax² + bx + c = 0 hasta llegar a la fórmula cuadrática. Compare su resultado con la hoja de fórmulas del GED. (3) No pierdo soluciones: en cada resolución se olvidó el signo ±. Encuentre la solución que falta y escriba las dos: (x + 2)² = 9 → x = 1; (x − 4)² = 25 → x = 9; (x + 1)² = 7 → x = −1 + √7. Después haga varios ejercicios de cada actividad de la página de práctica, resolviéndolos primero en el cuaderno, y anote los que falle para repasarlos. Unos 60 minutos; revise su trabajo con la lista de autoevaluación de esta lección.

➡️Lo que viene

En esta lección se aprendió a completar el cuadrado: un método que funciona siempre, sumando (b/2)² para formar un binomio al cuadrado y sacando la raíz con el signo ±. También se vio que este procedimiento, aplicado a la ecuación general, produce la fórmula cuadrática.

En la Lección 4.3 · La fórmula cuadrática, el discriminante y aplicaciones se usará esa fórmula para resolver cualquier ecuación cuadrática de forma directa, se aprenderá a predecir el número de soluciones con el discriminante y se modelarán situaciones reales como la trayectoria de un proyectil.

📘Términos clave

completar el cuadrado
Sumar (b/2)² a x² + bx para formar un binomio al cuadrado.
trinomio cuadrado perfecto
x² + bx + (b/2)² = (x + b/2)²
±
«Más o menos»: un número y su opuesto, las dos raíces cuadradas.
fórmula cuadrática
x = (−b ± √(b² − 4ac)) / 2a
