Lección 4.1 · Resolver ecuaciones cuadráticas por factorización

Resuelva una ecuación cuadrática igualándola a cero, factorizando e igualando cada factor a cero; después verifique e interprete las soluciones.

⏱️ Unas 4 horas con la práctica y la tarea · tome descansos ✏️ Sin calculadora

🎯Lo que va a aprender

Al terminar esta lección, usted podrá:

  • Comprender y aplicar la propiedad del producto cero.
  • Resolver ecuaciones cuadráticas por factorización con un procedimiento de cinco pasos.
  • Llevar una ecuación a la forma estándar ax² + bx + c = 0 antes de factorizar.
  • Resolver problemas aplicados y verificar ambas soluciones en la ecuación original.

1La propiedad del producto cero

Conexión con el tema anterior. En el Tema 3 se aprendió a factorizar polinomios. Esa destreza ahora cobra un propósito poderoso: resolver ecuaciones. Una ecuación cuadrática es una igualdad con un término x²; resolverla significa hallar los valores de x que la hacen cierta. La factorización, junto con una propiedad muy sencilla del número cero, abre la puerta a esas soluciones.

El número cero tiene una propiedad única en la multiplicación:

Si A · B = 0, entonces A = 0 o B = 0.

En palabras: si el producto de dos cantidades es cero, al menos una de ellas tiene que ser cero. No hay otra manera de que un producto dé cero.

Idea con números

Si 7 · B = 0, ¿cuánto vale B? Necesariamente B = 0, porque 7 no es cero. Lo mismo ocurre con factores que contienen x: si (x − 2)(x + 5) = 0, entonces x − 2 = 0 o x + 5 = 0, es decir, x = 2 o x = −5.

La clave es el cero

Esta propiedad solo funciona cuando el producto es igual a cero. Si un producto da 12, los factores podrían ser 3 y 4, 2 y 6, 24 y 0.5… Por eso, antes de aplicarla, la ecuación debe estar igualada a cero (forma estándar).

2Los cinco pasos

Para resolver una ecuación cuadrática por factorización se sigue siempre este procedimiento:

Los cinco pasos para resolver una ecuación cuadrática por factorización
PasoAcción
1Llevar la ecuación a la forma estándar: ax² + bx + c = 0.
2Factorizar el lado izquierdo.
3Igualar cada factor a cero.
4Resolver cada ecuación lineal.
5Verificar ambas soluciones en la ecuación original.

↔ Deslice la tabla horizontalmente para ver todas las columnas.

Ejemplo 1 · Resolver x² + 5x + 6 = 0.

1Ya está en forma estándar.

2Se factoriza. (x + 2)(x + 3) = 0.

3Se iguala cada factor a cero. x + 2 = 0 o x + 3 = 0.

4Se resuelve. x = −2 o x = −3.

5Verificación. (−2)² + 5(−2) + 6 = 4 − 10 + 6 = 0. Correcto.

✓Soluciones. x = −2 y x = −3.

Ejemplo 2 · Con diferencia de cuadrados. Resolver x² − 9 = 0.

1Ya está en forma estándar.

2Se factoriza. (x + 3)(x − 3) = 0.

3Se iguala cada factor a cero. x + 3 = 0 o x − 3 = 0.

✓Soluciones. x = −3 y x = 3.

3Llevar a la forma estándar primero

Muchas ecuaciones no vienen igualadas a cero. El paso 1 es siempre reorganizarlas pasando todos los términos a un lado. Al pasar un término al otro lado, cambia de signo, porque se hace la misma operación en ambos lados.

Ejemplo 3 · Resolver x² = 9.

1Forma estándar. x² − 9 = 0.

2Se factoriza. (x + 3)(x − 3) = 0.

✓Soluciones. x = 3 y x = −3.

Ejemplo 4 · El cero como solución. Resolver x² = 5x.

1Forma estándar. x² − 5x = 0.

2Factor común. x(x − 5) = 0.

3Cada factor igual a cero. x = 0 o x − 5 = 0.

✓Soluciones. x = 0 y x = 5.

No divida entre x

En x² = 5x, dividir ambos lados entre x haría perder la solución x = 0. Siempre se lleva todo a un lado y se factoriza; así no se pierde ninguna solución.

4Aplicación: problemas de área

Las ecuaciones cuadráticas modelan situaciones reales, especialmente de área y de movimiento. En estos problemas hay que interpretar las soluciones: a veces una de ellas no tiene sentido en el contexto.

Ejemplo 5 · El área de un rectángulo es de 54 pies cuadrados. El largo mide 3 pies más que el ancho. ¿Cuánto mide cada lado?

1Sea x el ancho. El largo es x + 3. Área: x(x + 3) = 54.

2Forma estándar. x² + 3x − 54 = 0.

3Se factoriza. (x + 9)(x − 6) = 0.

4Se resuelve. x = −9 o x = 6.

5Se interpreta. Una longitud no puede ser negativa, así que x = 6.

✓Respuesta. El ancho mide 6 pies y el largo, 9 pies.

Interprete el contexto

En problemas de longitudes, tiempos o cantidades, se descartan las soluciones negativas o sin sentido físico. Siempre vale la pena preguntarse: ¿esta solución es posible en la situación real?

5Tarea

Esta es práctica independiente. Calcule alrededor de una hora, con su cuaderno abierto.

  • La página de práctica. Abra la página de práctica de esta lección y haga cada actividad. Los ejercicios cambian cada vez. Haga por lo menos 10 en cada actividad y siga hasta acertar 8 de 10 al primer intento. El marcador de cada actividad lleva la cuenta por usted.
  • Papel y lápiz. Para hacer por su cuenta, con el cuaderno abierto: (1) Resuelva ocho ecuaciones por factorización, escribiendo los cinco pasos y cuántas soluciones distintas obtiene en cada una: x² + 7x + 10 = 0, x² − 3x − 18 = 0, 2x² + 5x − 3 = 0, x² + 6x + 9 = 0, x² = 9, x² = 5x, x² − 8x = −15 y 3x² = 12x. Las cuatro últimas hay que llevarlas primero a la forma estándar. (2) El rectángulo: su largo mide 3 pies más que su ancho y su área es de 54 pies cuadrados. Plantee la ecuación, resuélvala por factorización y explique por qué se descarta una de las soluciones. Después invente un problema parecido y resuélvalo. (3) Siempre verifico: sustituya cada solución en su ecuación y corrija las que no cumplan la igualdad, describiendo el error en una frase. x² − 5x + 6 = 0 → x = 2 o x = 3; x² + x − 12 = 0 → x = −3 o x = 4; x² = 4x → x = 4. Después haga una ronda de cada actividad de la página de práctica, resolviendo cada ejercicio en papel antes de escribir la respuesta. Unos 60 minutos; revise su trabajo con la lista de autoevaluación de esta lección.
  • En su vida diaria. Piense en un jardín, una alfombra o una ventana de su casa cuyo largo sea unos pies mayor que su ancho. Mídalo, halle su área y escriba la ecuación que permitiría a otra persona hallar el ancho sabiendo solo el área.

➡️Lo que viene

En esta lección se resolvieron ecuaciones cuadráticas por factorización, aplicando la propiedad del producto cero con un procedimiento de cinco pasos, y se interpretaron las soluciones en problemas de área.

Pero no todas las ecuaciones cuadráticas se factorizan con números enteros. En la Lección 4.2 · Completar el cuadrado se aprenderá un método que funciona siempre, se factorice o no la ecuación. Además, completar el cuadrado es el origen de la fórmula cuadrática de la Lección 4.3.

📘Términos clave

ecuación cuadrática
Una ecuación cuya mayor potencia de x es x².
forma estándar
ax² + bx + c = 0
propiedad del producto cero
Si A · B = 0, entonces A = 0 o B = 0.
solución (raíz)
Un valor de x que hace cierta la ecuación.
solución descartada
Una solución algebraica correcta que no tiene sentido en la situación, como una longitud negativa.
