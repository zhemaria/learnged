Lección 8.1 · Funciones cuadráticas: la parábola, el vértice y los interceptos

Lea la forma de una parábola, halle su vértice, su eje y sus interceptos, y use el vértice para resolver problemas de máximo y mínimo.

⏱️ Unas 4 horas con la práctica y la tarea · tome descansos 🧮 Se permite calculadora

🎯Lo que va a aprender

Al terminar esta lección, usted podrá:

  • Identificar hacia dónde abre una parábola según el signo de a.
  • Calcular el vértice con x = −b/(2a) y el eje de simetría.
  • Encontrar los interceptos con el eje x y con el eje y.
  • Usar el vértice para resolver problemas de máximo y mínimo en contexto.

1La parábola y su forma

Conexión con el tema anterior. En el Tema 7 se clasificaron las funciones cuadráticas por su patrón. Ahora se estudian a fondo: su gráfica (la parábola), su punto más importante (el vértice) y cómo modelan situaciones de máximo o mínimo, como la altura de un proyectil o el beneficio de un negocio.

2El vértice y el eje de simetría

El vértice es el punto más alto o más bajo de la parábola. Su coordenada x se halla con la fórmula, y la y se obtiene evaluando la función. El eje de simetría es la recta vertical que pasa por el vértice.

x del vértice = −b / (2a) · eje de simetría: x = −b / (2a)

Ejemplo 1 · Hallar el vértice y el eje de f(x) = x² − 4x + 3.

1Aquí a = 1 y b = −4. x del vértice: −(−4) / (2 · 1) = 4/2 = 2.

2La y del vértice: f(2) = (2)² − 4(2) + 3 = 4 − 8 + 3 = −1.

✓Respuesta. Vértice (2, −1); eje de simetría x = 2; como a > 0, es un mínimo.

Ejemplo 2 · Interceptos de f(x) = x² − 4x + 3.

1Con y: f(0) = 3, así que (0, 3).

2Con x: x² − 4x + 3 = 0 → (x − 1)(x − 3) = 0 → x = 1 y x = 3, así que (1, 0) y (3, 0).

Hallar los interceptos con el eje x de una parábola es exactamente resolver una ecuación cuadrática. El discriminante b² − 4ac dice cuántos hay: positivo, dos; cero, uno (el vértice toca el eje); negativo, ninguno.

4Máximo y mínimo en contexto

El vértice resuelve problemas reales: la altura máxima de un proyectil, el beneficio máximo de un negocio, el área máxima de un terreno. Si la parábola abre hacia abajo, el vértice es el máximo; si abre hacia arriba, es el mínimo.

Ejemplo 3 · El proyectil. La altura es h(t) = −16t² + 64t + 5 pies (t en segundos). ¿Cuándo alcanza la altura máxima y cuál es?

1Como a = −16 < 0, abre hacia abajo: el vértice es un máximo.

2t del vértice: −64 / (2 · −16) = −64 / −32 = 2 segundos.

✓Altura máxima: h(2) = −16(4) + 64(2) + 5 = −64 + 128 + 5 = 69 pies.

Ejemplo 4 · El beneficio. El beneficio es B(x) = −2x² + 120x − 800 dólares. ¿Cuántas unidades lo maximizan?

1x del vértice: −120 / (2 · −2) = −120 / −4 = 30 unidades.

✓Beneficio máximo: B(30) = −2(900) + 120(30) − 800 = −1,800 + 3,600 − 800 = $1,000.

📘Términos clave

parábola
La gráfica en forma de U de una función cuadrática.
vértice
El punto más alto o más bajo de una parábola; su x es −b/(2a).
eje de simetría
La recta vertical que pasa por el vértice: x = −b/(2a).
intercepto
Un punto donde la gráfica cruza un eje.
