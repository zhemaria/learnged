El método gráfico

›

Mueva la pendiente (m) y el intercepto (b) de cada recta y = mx + b y observe cómo se desplaza el punto de cruce. Cuando las pendientes son iguales, las rectas son paralelas o la misma.

2

Conectar lo gráfico con lo algebraico

›

Para saber el tipo de sistema antes de graficar, se escribe cada ecuación como y = mx + b. Pendientes distintas: las rectas se cruzan. Misma pendiente y distinto intercepto: paralelas. Misma pendiente y mismo intercepto: la misma recta.

Practique: ¿qué tipo de sistema es?

El punto de equilibrio

›

Costos: C = costos fijos + costo por unidad · x. Ingresos: I = precio · x. El punto de equilibrio es donde C = I.
