The greenhouse: isolate the variable

›

Group A and group B start the same: usual light, water, temperature, and soil. Change the factors of either group and press Run the trial. After six weeks you will see the mean height of each group and whether the result lets you conclude anything. The model always gives the same result for the same setup, as a good experiment should.

Lab notebook: each trial, what changed between A and B, the mean height of each group, and whether a conclusion is possible
TrialWhat changed between A and BHeight A (cm)Height B (cm)Can you conclude anything?
You have not run any trials yet.

Challenge: find the best light for the plants. Then find the best soil. How many trials did you need? Did you ever change two things at once?
