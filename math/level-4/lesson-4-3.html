Lesson 4.3 · The quadratic formula, the discriminant, and applications

Solve any quadratic equation with the formula, predict the number of solutions with the discriminant, and model the path of a ball.

1The quadratic formula

A link with Lesson 4.2. In Lesson 4.2 you saw that completing the square in the general equation produces the quadratic formula. Now you use the formula directly: it solves any quadratic equation, whether it factors or not. In this lesson you may use the calculator and the GED formula sheet.

For any equation in standard form ax² + bx + c = 0, the solutions are:

x = (−b ± √(b² − 4ac)) / 2a

The first step is always to identify a, b, and c with their signs. For example, in 2x² − 4x − 3 = 0: a = 2, b = −4, c = −3.

Watch the signs of b and c

The value of b includes its sign. In −b, a negative b becomes positive. Substituting with parentheses, for example (−4)², avoids the most common sign mistakes: (−4)² = 16, never −16.

2The discriminant: how many solutions?

The part of the formula inside the square root, b² − 4ac, is called the discriminant. Its sign tells you how many real solutions the equation has before you solve it:

How the sign of the discriminant tells the number of real solutions
Discriminant b² − 4acReal solutionsThe parabola and the x-axis
greater than 02 different solutionscrosses it at 2 points
equal to 01 solution (a double one)touches it at 1 point
less than 0no real solutionsdoes not touch it

Example 1: how many solutions does x² + 3x + 5 = 0 have?

1a = 1, b = 3, c = 5.

2Discriminant: (3)² − 4(1)(5) = 9 − 20 = −11.

3Since −11 < 0, there are no real solutions.

✓Answer. No real solution.

Find the discriminant first

Before you solve, ask: how many solutions do I expect? Then you will know whether the equation has two, one, or none, and you will catch a mistake if your result does not match.

3Solving with the formula

Example 2: whole-number solutions. Solve x² + 5x + 6 = 0 with the formula.

1a = 1, b = 5, c = 6.

2Discriminant: 5² − 4(1)(6) = 25 − 24 = 1.

3x = (−5 ± √1) / 2 = (−5 ± 1) / 2.

4x = −2 or x = −3.

✓Solutions. x = −2 and x = −3.

Example 3: with the calculator (the root is not exact). Solve 2x² − 4x − 3 = 0.

1a = 2, b = −4, c = −3.

2Discriminant: (−4)² − 4(2)(−3) = 16 + 24 = 40.

3x = (4 ± √40) / 4. With the calculator, √40 ≈ 6.32.

4x ≈ (4 + 6.32) / 4 ≈ 2.58 or x ≈ (4 − 6.32) / 4 ≈ −0.58.

✓Solutions (rounded). x ≈ 2.58 and x ≈ −0.58.

4Application: the path of a ball

Quadratic functions model the height of an object thrown into the air. If h(t) is the height (in feet) after t seconds, solving h(t) = 0 tells you when it hits the ground, and solving h(t) = a value tells you when it reaches that height.

h(t) = −16t² + v₀t + h₀

v₀ is the starting speed (in feet per second) and h₀ is the height it is thrown from (in feet). The −16 comes from gravity and is always the same when you measure in feet.

Example 4: a ball is thrown and its height is h(t) = −16t² + 96t + 5. When does it hit the ground? (use the calculator)

1Hitting the ground means h(t) = 0: −16t² + 96t + 5 = 0.

2a = −16, b = 96, c = 5.

3Discriminant: 96² − 4(−16)(5) = 9,216 + 320 = 9,536. √9,536 ≈ 97.65.

4t = (−96 ± 97.65) / (−32). t ≈ −0.05 or t ≈ 6.05.

5Throw out the negative root; t ≈ 6.05 is left.

✓Answer. The ball hits the ground after about 6.05 seconds.

Interpret the situation

In problems about time and height, negative solutions make no sense (time is not negative). The valid solution is the one that fits the real situation.

5Three methods: which one is best?

You now know three ways to solve a quadratic equation. Knowing which to choose saves time:

The three methods to solve quadratic equations and when each one is best
MethodWhen is it best?
FactoringWhen the trinomial factors easily with whole numbers.
Completing the squareWhen a = 1 and b is even; useful to understand the structure.
Quadratic formulaAlways works; best when it does not factor or the roots are not whole numbers.

↔ Slide the table sideways to see all the columns.

Three questions, in order

Does the trinomial factor easily with whole numbers? Then factor. If not, is a = 1 and b even? Then complete the square. In any other case, use the quadratic formula, which always works.

Then check with the formula the ones that have solutions: x² − 6x + 9 = 0, x² + 2x + 5 = 0, 2x² − 3x − 2 = 0, x² − 4x + 1 = 0, 4x² + 4x + 1 = 0, and 3x² + x + 2 = 0. Then do several exercises of each activity on the practice page, solving them in your notebook first, and write down the ones you miss to review them.   • In your daily life. Toss a ball straight up outside and count the seconds until it lands. Use h(t) = −16t² + v₀t + 4 (your hand is about 4 feet high) and try values of v₀ until the landing time matches what you counted. What starting speed did you throw it with?

📘Key words

quadratic formula
x = (−b ± √(b² − 4ac)) / 2a
discriminant
b² − 4ac: positive, two solutions; zero, one; negative, none that are real.
double solution
When the discriminant is 0, the two solutions are the same number.
parabola
The U-shaped graph of a quadratic function. Its x-intercepts are the real solutions.
vertex
The highest (or lowest) point of a parabola; for a ball, its maximum height.
