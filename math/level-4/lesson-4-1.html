Lesson 4.1 · Solving quadratic equations by factoring

Solve a quadratic equation by writing it equal to zero, factoring, and setting each factor equal to zero; then check and interpret the solutions.

⏱️ About 4 hours with practice and homework · take breaks ✏️ No calculator

🎯What you will learn

When you finish this lesson, you will be able to:

  • Understand and use the zero product property.
  • Solve quadratic equations by factoring with a five-step method.
  • Write an equation in standard form ax² + bx + c = 0 before factoring.
  • Solve word problems and check both solutions in the original equation.

1The zero product property

A link with Topic 3. In Topic 3 you learned to factor polynomials. Now that skill gets a powerful purpose: solving equations. A quadratic equation is an equation with an x² term; solving it means finding the values of x that make it true. Factoring, together with a very simple property of the number zero, opens the door to those solutions.

Zero has a property in multiplication that no other number has:

If A · B = 0, then A = 0 or B = 0.

In words: if the product of two quantities is zero, at least one of them has to be zero. There is no other way for a product to be zero.

The idea with numbers

If 7 · B = 0, what is B? It has to be 0, because 7 is not zero. The same happens with factors that contain x: if (x − 2)(x + 5) = 0, then x − 2 = 0 or x + 5 = 0, so x = 2 or x = −5.

The key is the zero

This property only works when the product equals zero. If a product equals 12, the factors could be 3 and 4, 2 and 6, 24 and 0.5… That is why the equation must equal zero (standard form) before you use it.

2The five steps

To solve a quadratic equation by factoring, always follow these steps:

The five steps to solve a quadratic equation by factoring
StepWhat to do
1Write the equation in standard form: ax² + bx + c = 0.
2Factor the left side.
3Set each factor equal to zero.
4Solve each linear equation.
5Check both solutions in the original equation.

↔ Slide the table sideways to see all the columns.

Example 1: solve x² + 5x + 6 = 0.

1It is already in standard form.

2Factor. (x + 2)(x + 3) = 0.

3Each factor equals zero. x + 2 = 0 or x + 3 = 0.

4Solve. x = −2 or x = −3.

5Check. (−2)² + 5(−2) + 6 = 4 − 10 + 6 = 0. Right.

✓Solutions. x = −2 and x = −3.

Example 2: with a difference of squares. Solve x² − 9 = 0.

1It is already in standard form.

2Factor. (x + 3)(x − 3) = 0.

3Each factor equals zero. x + 3 = 0 or x − 3 = 0.

✓Solutions. x = −3 and x = 3.

3Standard form first

Many equations do not come equal to zero. Step 1 is always to rearrange them, moving every term to one side. When a term moves to the other side, its sign changes, because you do the same operation on both sides.

Example 3: solve x² = 9.

1Standard form. x² − 9 = 0.

2Factor. (x + 3)(x − 3) = 0.

✓Solutions. x = 3 and x = −3.

Example 4: zero as a solution. Solve x² = 5x.

1Standard form. x² − 5x = 0.

2Common factor. x(x − 5) = 0.

3Each factor equals zero. x = 0 or x − 5 = 0.

✓Solutions. x = 0 and x = 5.

Do not divide by x

In x² = 5x, dividing both sides by x would lose the solution x = 0. Always move everything to one side and factor; that way you do not lose any solution.

4Applications: area problems

Quadratic equations model real situations, especially of area and motion. In these problems you must interpret the solutions: sometimes one of them makes no sense in the situation.

Example 5: the area of a rectangle is 54 square feet. The length is 3 feet more than the width. How long is each side?

1Let x be the width. The length is x + 3. Area: x(x + 3) = 54.

2Standard form. x² + 3x − 54 = 0.

3Factor. (x + 9)(x − 6) = 0.

4Solve. x = −9 or x = 6.

5Interpret. A length cannot be negative, so x = 6.

✓Answer. The width is 6 feet and the length, 9 feet.

Interpret the situation

In problems about lengths, times, or amounts, throw out negative solutions or solutions that make no physical sense. Always ask: is this solution possible in the real situation?

5Homework

This is independent practice. Plan for about one hour, with your notebook open.

  • The practice page. Open the practice page for this lesson and do each activity. The exercises change every time. Do at least 10 in each activity, and keep going until you get 8 out of 10 right on the first try. The score under each activity keeps count for you.
  • Paper and pencil. For your own work, with your notebook open: (1) Solve eight equations by factoring, writing the five steps and how many different solutions you get in each: x² + 7x + 10 = 0, x² − 3x − 18 = 0, 2x² + 5x − 3 = 0, x² + 6x + 9 = 0, x² = 9, x² = 5x, x² − 8x = −15, and 3x² = 12x. The last four must first be written in standard form. (2) The rectangle: its length is 3 feet more than its width and its area is 54 square feet. Write the equation, solve it by factoring, and explain why one solution is thrown out. Then make up a similar problem and solve it. (3) I always check: substitute each solution in its equation and correct the ones that do not make it true, describing the mistake in one sentence. x² − 5x + 6 = 0 → x = 2 or x = 3; x² + x − 12 = 0 → x = −3 or x = 4; x² = 4x → x = 4. Then do a round of each activity on the practice page, solving each exercise on paper before you type the answer. About 60 minutes; check your work with the checklist of this lesson.
  • In your daily life. Think of a garden, a rug, or a window at home whose length is a few feet more than its width. Measure it, find its area, and write the equation that would let someone find the width from the area alone.

📘Key words

quadratic equation
An equation whose highest power of x is x².
standard form
ax² + bx + c = 0
zero product property
If A · B = 0, then A = 0 or B = 0.
solution (root)
A value of x that makes the equation true.
extraneous answer
A correct algebraic solution that makes no sense in the situation, such as a negative length.
