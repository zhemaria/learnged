Lesson 7.1 · Systems of linear inequalities: graphing the solution region

Graph linear inequalities with a solid or dashed line, choose the side with the test point, find the feasible region of a system, and check points.

⏱️ About 4 hours with practice and homework · take breaks 🧮 Calculator allowed

🎯What you will learn

When you finish this lesson, you will be able to:

  • Graph a linear inequality: a solid or dashed line and the correct shaded side.
  • Use the test point (0, 0) to choose the side to shade.
  • Graph a system of inequalities and find the feasible region (the intersection).
  • Check whether a point belongs to the solution region.

1Graphing a linear inequality

A link with Topic 6. In Topic 6, the solution of a system of equations was a point. In Topic 7 the equal sign (=) becomes an inequality sign (<, ≤, >, ≥), and the solution is no longer a point but a whole region of the plane: many points meet the conditions at the same time.

Graphing an inequality has two parts: the boundary line and the shading of the correct side.

How to draw the boundary line for each inequality symbol
SymbolBoundary line
< or >Dashed (the boundary is not included)
≤ or ≥Solid (the boundary is included)

On the graph, y ≤ x + 1 has a solid line (because of the ≤), and the side below the line is shaded: the side where the test point (0, 0) is.

2The test point method

To decide which side of the line to shade, choose a test point that is not on the line (almost always (0, 0)) and substitute it into the inequality.

Example 1: graph 2x + y > 4.

1The line is dashed (because of the > symbol).

2Test (0, 0): 2(0) + 0 > 4, that is, 0 > 4. False.

✓Shade. Because it is false, shade the side opposite the origin.

True or false

If the test point makes the inequality true, shade its side; if it makes it false, shade the other side. If the line goes through (0, 0), use another point, such as (1, 0).

3A system of inequalities: the feasible region

A system of inequalities is graphed one inequality at a time. The feasible region is where all the shadings overlap: the intersection of the half-planes. Every point of that region meets all the inequalities at once.

The shaded triangle is the feasible region of the system x ≥ 0, y ≥ 0, and x + y ≤ 4. All its points meet the three conditions.

Each inequality cuts, never adds

When you add one more condition, the region can only stay the same or get smaller. Sometimes it disappears completely: then the system has no solution.

4Checking whether a point is in the region

To check whether a point is in the solution region, substitute it into all the inequalities of the system. If it meets all of them, it belongs to the region; if it fails even one, it does not.

Example 2: is (1, 1) in the region of the system y ≤ x + 1 and y ≥ 0?

1First: 1 ≤ 1 + 1, that is, 1 ≤ 2. True.

2Second: 1 ≥ 0. True.

✓Answer. Yes, (1, 1) belongs to the region.

5Homework

This is independent practice. Plan for about one hour, with your notebook open.

  • The practice page. Open the practice page for this lesson and do each activity. The exercises change every time. Do at least 10 in each activity, and keep going until you get 8 out of 10 right on the first try. The score under each activity keeps count for you.
  • Paper and pencil. For your own work, with your notebook and graph paper: (1) The production budget: a workshop makes x chairs and y tables. Each chair takes 2 hours and each table 4, with at most 40 hours (2x + 4y ≤ 40). Each chair uses 1 board and each table 3, and there are 24 boards (x + 3y ≤ 24). Also, x ≥ 0 and y ≥ 0. Graph the system, shade the feasible region, and write three combinations (x, y) that can be made and one that cannot. (2) Solid or dashed: for each inequality, decide how to draw the line and which side to shade, using the test point (0, 0): y > 2x − 1; y ≤ −x + 3; 2x + y ≥ 4; x − y < 2; y ≥ 3; x < −1. (3) A viable point? With the system y ≤ x + 2, y > −x, x ≤ 3, substitute each point into the three inequalities and say whether it belongs to the region: (0, 1), (2, −3), (3, 5), (4, 0), and (−1, 1). For those that do not, explain in one sentence which inequality they fail. Pay close attention to the ones that fall on a line. Then do several exercises of each activity on the practice page. About 60 minutes; check your work with the checklist of this lesson.

📘Key words

boundary line
The line ax + by = c that separates the two half-planes.
half-plane
Each of the two sides into which a line divides the plane.
test point
A point off the line, usually (0, 0), substituted to choose the side to shade.
feasible region
The points that meet all the inequalities of a system at once.
