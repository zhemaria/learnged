Lesson 5.1 · Simplifying rational expressions: factor and cancel

Simplify a rational expression by factoring the top and the bottom and cancelling only common factors, and find the values excluded from the domain.

⏱️ About 4 hours with practice and homework · take breaks ✏️ No calculator

🎯What you will learn

When you finish this lesson, you will be able to:

  • Relate simplifying rational expressions to simplifying fractions of numbers.
  • Simplify by factoring the numerator and the denominator and cancelling common factors.
  • Find the values excluded from the domain.
  • Tell a factor from a term, and avoid cancelling terms.

1Just like fractions of numbers

A link with Topics 3 and 4. In Topics 3 and 4, factoring was the key tool. It is again: a rational expression is a fraction whose numerator and denominator are polynomials. To simplify it you factor the top and the bottom and cancel the common factors, exactly as with fractions of numbers.

To simplify 12/18, you factor the top and the bottom and cancel the common factor:

121812 over 18 = 2 · 63 · 62 times 6 over 3 times 6, with the 6 crossed out = 232 over 3

The 6 cancels because it is a factor (something that multiplies) on the top and on the bottom. With polynomials it works the same way:

(x + 3)(x − 3)(x + 3)(x − 2)x plus 3 times x minus 3, over x plus 3 times x minus 2, with x plus 3 crossed out = x − 3x − 2x − 3 over x − 2

2Simplifying algebraic fractions

There are three steps: factor the numerator, factor the denominator, and cancel the common factors.

Example 1: monomials. Simplify 6x² / 9x.

1Write it in factors: (3 · 2 · x · x) / (3 · 3 · x).

2Cancel the 3 and one x.

✓Answer. 2x / 3.

Example 2: with a trinomial. Simplify (x² + 5x + 6) / (x + 2).

1Factor the numerator: (x + 2)(x + 3).

2Cancel the common factor (x + 2).

✓Answer. x + 3.

Example 3: simplify (x² − 4) / (x² − x − 2).

1Numerator: (x + 2)(x − 2). Denominator: (x − 2)(x + 1).

2Cancel (x − 2).

✓Answer. (x + 2) / (x + 1).

3Values excluded from the domain

A fraction can never have a denominator of zero: division by zero is not defined. The excluded values are the ones that make the original denominator zero (before cancelling). To find them, factor the denominator and set each factor equal to zero.

Example 4: which values are excluded in (x + 1) / (x² − 9)?

1Factor the denominator: (x + 3)(x − 3).

2Set each factor equal to zero: x + 3 = 0 or x − 3 = 0.

✓Excluded values. x = −3 and x = 3.

Write them down before cancelling

Even if a factor cancels when you simplify, the value that made it zero is still excluded. That is why you read the excluded values in the original denominator. And watch the sign: (x − 3) is zero at x = 3, and (x + 2) at x = −2.

4The trap: factors, not terms

You can only cancel factors (things that multiply everything), never terms (things that are added or subtracted).

The difference between a factor and a term in the numerator
ExpressionWhat is the x?Can it cancel?
x(x + 4)A factor: it multiplies the whole parenthesesYes
x + 4A term: it is addedNo

Example 5: done right. Simplify (x + 2) / (x² − 4).

1Factor the denominator: (x + 2)(x − 2).

2(x + 2) is a common factor: it cancels.

✓Answer. 1 / (x − 2).

A wrong cancellation

In (x + 4) / x you cannot cancel the x to get 4, because on top the x is added (it is a term, not a factor). In the same way, in (x + 3) / 3 the 3 is not a factor of the whole numerator, so it does not cancel. Cancelling terms is the most common mistake with algebraic fractions. The quick test: if there is a + or − sign between what you want to cancel and the rest, with no parentheses grouping them, it is a term.

5Homework

This is independent practice. Plan for about one hour, with your notebook open.

  • The practice page. Open the practice page for this lesson and do each activity. The exercises change every time. Do at least 10 in each activity, and keep going until you get 8 out of 10 right on the first try. The score under each activity keeps count for you.
  • Paper and pencil. For your own work, with your notebook open: (1) Which values do I exclude? Simplify these eight expressions and write down the excluded values from the original denominator: 6x / 9x², (x² − 9) / (x + 3), (x² + 5x + 6) / (x² − 4), (2x + 8) / (x² + 4x), (x² − x − 12) / (x² − 16), (3x − 6) / (x² − 4x + 4), (x² − 25) / (x² − 10x + 25), and (4x² − 1) / (2x² + x). Mark in each one the factor you cancelled. (2) Mistake hunters: each simplification is wrong. Explain in one sentence why it cannot be cancelled and correct it: (x + 5) / 5 = x; (x² + 4) / (x + 2) = x + 2; (x + 3) / (x + 6) = 1/2. (3) From numbers to polynomials: simplify 12/18 and, next to it, (x² + 5x + 6) / (x² + 6x + 9), writing the factor-and-cancel steps side by side. Then make up two more pairs. Then do several exercises of each activity on the practice page, solving them in your notebook first. About 60 minutes; check your work with the checklist of this lesson.
  • In your daily life. Explain to someone at home why (x + 4) / x is not 4. Ask them to try x = 2: (2 + 4) / 2 = 3, not 4. A number check like this catches a wrong cancellation every time.

📘Key words

rational expression
A fraction whose numerator and denominator are polynomials.
factor
Something that multiplies the whole expression.
term
A part of an expression separated by + or −.
excluded value
A value of x that makes the original denominator zero.
domain
All the values that x can take.
