1What is a function? The function machine

A link with Lesson 7.1. In Lesson 7.1 you worked with regions of the plane. Now comes one of the central ideas of the GED test: the function. A function is a rule that takes an input and gives back exactly one output. It is the base of all of Topic 8.

Think of a function as a machine: a number goes in (the input x), the machine applies a rule, and a result comes out (the output f(x)). The key condition: each input gives only one output.

The input test

If the same input (the same value of x) had two different outputs, the relation would not be a function. A machine that gave two different results for the same number would be broken.

2The vertical line test

On a graph, a relation is a function if no vertical line cuts it at more than one point. If some vertical line touches the graph two or more times, that input would have several outputs, and the relation would not be a function.

The parabola is a function: any vertical line cuts it only once. A circle or a parabola “lying on its side” would fail the test.

3f(x) notation: evaluating functions

The notation f(x) is read “f of x” and means the output of the function for the input x. To evaluate, substitute the value of x and simplify following the order of operations (PEMDAS).

Example 1: if f(x) = 2x − 3, find f(4).

1Substitute x = 4: f(4) = 2(4) − 3.

2Simplify: 8 − 3 = 5.

✓Answer. f(4) = 5.

Example 2 (quadratic): if f(x) = x² + 1, find f(−2).

1Substitute: f(−2) = (−2)² + 1.

2Simplify: 4 + 1 = 5.

✓Answer. f(−2) = 5.

Careful with the signs

When you evaluate at a negative number, use parentheses: (−2)² = 4, not −4. The parentheses prevent the most common sign mistake.

4Domain and range

The domain is all the input values (x). The range is all the output values (y). For a set of points, just list the first coordinates (domain) and the second coordinates (range).

Example 3: for the points {(1, 2), (3, 4), (5, 6)}:

1Domain (inputs): {1, 3, 5}.

2Range (outputs): {2, 4, 6}.

5Composition of functions

What if the output of one function goes into another? That is the composition of functions. The GED test asks it as “if f(x) = … and g(x) = …, what is f(g(3))?”, and you solve it with what you already know: evaluate functions, twice, in the right order.

In f(g(x)), read “f of g of x,” there are two machines in a chain. First x goes into machine g. What comes out, g(x), then goes into machine f. Some books write (f ∘ g)(x): it means the same thing.

Example 4: if f(x) = 3x − 2 and g(x) = x + 4, find f(g(2)).

1Inside first: g(2) = 2 + 4 = 6.

2Then outside: f(6) = 3(6) − 2 = 18 − 2 = 16.

✓Answer. f(g(2)) = 16.

The order matters

The function closest to the x acts first: in f(g(x)), g goes first. With f(x) = 2x and g(x) = x + 5, f(g(3)) = f(8) = 16, but g(f(3)) = g(6) = 11. And a composition is not a product: f(g(2)) is not f(2) · g(2).

Example 5: if f(x) = 3x + 1 and g(x) = x − 2, write the expression of f(g(x)).

1Put g(x) inside f, with parentheses: f(g(x)) = 3(x − 2) + 1.

2Distribute and combine: 3x − 6 + 1 = 3x − 5.

3Check with x = 4: g(4) = 2 and f(2) = 7; with the formula, 3(4) − 5 = 7.

✓Answer. f(g(x)) = 3x − 5.

6Homework

This is independent practice. Plan for about one hour, with your notebook open.

  • The practice page. Open the practice page for this lesson and do each activity. The exercises change every time. Do at least 10 in each activity, and keep going until you get 8 out of 10 right on the first try. The score under each activity keeps count for you.
  • Paper and pencil. For your own work, with your notebook and graph paper: (1) Function or not? Classify these ten relations and justify each decision with the input test or the vertical line test (draw the graphs): {(1, 2), (2, 4), (3, 6)}; {(1, 2), (1, 5), (3, 4)}; {(−2, 4), (2, 4), (0, 0)}; {(3, 1), (3, 2), (3, 3)}; y = 3x − 2; x = y²; y = x²; x² + y² = 9; x = 4; y = 4. (2) Evaluate the machine: with f(x) = 2x² − 3x + 1, find f(0), f(1), f(−2), and f(1/2). Write each substitution in parentheses and explain what would happen with f(−2) without them. (3) Domain and range: write the domain and range of y = 2x + 1, y = x², y = 2ˣ, and y = 1/x, and classify each as linear, quadratic, exponential, or rational. (4) Composition: with f(x) = 2x − 1 and g(x) = x² + 3, find f(g(0)), f(g(2)), g(f(0)), and g(f(2)), always writing the inside result first. Then write the expressions of f(g(x)) and g(f(x)) for f(x) = 5x and g(x) = x − 3, and check them with x = 2. Then do several exercises of each activity on the practice page. About 70 minutes; check your work with the checklist of this lesson.
  • In your daily life. Think of two steps in your daily life where the result of one goes into the other, such as a discount and then the sales tax. Write each step as a function and compose them.

📘Key words

function
A rule that gives exactly one output for each input.
domain
All the input values (x) of a relation.
range
All the output values (y) of a relation.
composition
f(g(x)): the output of g goes into f.
