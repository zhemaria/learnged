Lesson 8.2 · Bar graphs and line graphs

Four practice activities on one page. The exercises change every time. If you make a mistake, you get a hint and another try.

On this page

  1. Read a bar graph
  2. Compare with a bar graph
  3. Read a line graph
  4. Choose the right graph
1

Read a bar graph

›

First check the scale: how much is each line worth? Then find the bar, go across to the scale, and read the number. A bar that ends halfway between two lines is worth the number halfway between them.

Practice: read the bar

↑ Back to contents
2

Compare with a bar graph

›

"How many more": subtract the two bars. "Together": add them.

Practice: compare

Type only the number.

↑ Back to contents
3

Read a line graph

›

Each point is a value at one time. The line goes up when the value increases and down when it decreases. The steepest part is where it changed the most. Read the scale: it may not start at 0.

Practice: read the line

↑ Back to contents
4

Choose the right graph

›

Bar graph: to compare categories (products, places, groups). Line graph: to show change over time (hours, months, years).

Practice: which graph?
