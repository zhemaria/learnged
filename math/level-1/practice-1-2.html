Lesson 1.2 · Adding and subtracting whole numbers

Three practice activities on one page. The exercises change every time, so you can practice as many times as you want. If you make a mistake, you get a hint and another try.

On this page

  1. Adding with regrouping ("carrying")
  2. Subtracting with regrouping ("borrowing")
  3. Checking with the opposite operation
1

Adding with regrouping ("carrying")

›

Only add digits in the same place: ones with ones, tens with tens. That is why we line up the numbers on the right. If a column adds up to 10 or more, write the ones digit and carry 1 to the column on the left. It is like trading ten $1 bills for one $10 bill.

One column at a time

The most common mistake: forgetting to add the 1 you carried in the next column.

Practice: add

Type digits only. You can use commas to separate the groups.

2

Subtracting with regrouping ("borrowing")

›

If the top digit in a column is smaller than the bottom digit, borrow 1 from the column on the left. It is worth 10 in your column, like breaking one $10 bill into ten $1 bills. If the column on the left is a 0, it borrows first, and that 0 becomes 9.

One column at a time

A common mistake: subtracting the smaller digit from the larger one in each column, no matter which one is on top. For 624 − 158, that gives 534 instead of 466.

Practice: subtract

Type digits only. You can use commas to separate the groups.

3

Checking with the opposite operation

›

Addition and subtraction are opposite operations: one undoes the other. That is how you check an answer without a calculator.

How to check
To check…do thisExample
an additionsubtract one of the numbers you added from the answer: you should get the other one367 + 158 = 525 → 525 − 158 = 367 ✓
a subtractionadd the number you subtracted to the answer: you should get the number you started with624 − 158 = 466 → 466 + 158 = 624 ✓
