The quotient rule

›

When you divide two powers with the same base, each factor on the bottom cancels a factor on the top. That is why the exponents are subtracted, always the top one minus the bottom one:

am ÷ an = am − n

Factor canceller

Change the top and bottom exponents. Also try the same number in both, or a bigger one on the bottom: that is how you discover the ideas of the next two modules.

Watch the order: subtract the top exponent minus the bottom one, never the other way around. And the base cannot be zero, because dividing by zero is not defined.

Practice: write the exponent of the answer

Type a whole number. If it is negative, start with the minus sign: −2 or -2.

Practice: with numbers in front

The numbers are divided; the exponents are subtracted.

The zero exponent

›

If you divide a power by itself, the answer is 1, because any number other than zero divided by itself is 1. But the quotient rule gives a3 ÷ a3 = a0. Both describe the same division, so they must be equal:

a0 = 1 (a ≠ 0)

The pattern of shrinking powers

Each time the exponent goes down by one, the value is divided by the base. Choose a base and follow the pattern down to zero.

The zero affects only its own base: (3x)0 = 1, because the zero reaches the whole parentheses; but 3x0 = 3 · 1 = 3, because the zero reaches only the x. In the same way, −50 = −1, while (−5)0 = 1.

3

Negative exponents

›

If the pattern keeps going past zero, each step still divides by the base, and fractions appear. A negative exponent means the reciprocal of the power with a positive exponent:

a−n = 1/an (a ≠ 0)

The pattern keeps going

Crossing the fraction bar: moving a factor from top to bottom, or from bottom to top, changes the sign of its exponent. So x−4 = 1/x4 and also 1/a−2 = a2.
A negative exponent does not make the number negative. 2−3 is not −8 and not −6: it is the positive fraction 1/8. The sign of the exponent only says “reciprocal.”

5

Checking with numbers

›

A correct simplification gives the same number as the original expression for any value of the letter. If you replace the letter with a number and get different values, there is a mistake for sure. It is the same check you would do on the calculator.

Choose the test number well: 0 does not work when there are divisions or negative exponents, and with 1 every power is 1, so the test tells you nothing. Use 2 or 3.

Practice: is the work correct?

First test with one or two values of x. Then decide.
